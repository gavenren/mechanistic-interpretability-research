# Checked sources and contribution boundary

Checked 13 October 2026. This is a focused source check, not proof that no closer work exists. The study applies established ideas to a fixed internal-event selection test.

| Primary source and checked version | Established overlap and boundary |
|---|---|
| Ammar Bitar, Rafael Rosales, Michael Paulitsch (2023), [Gradient-based feature-attribution explainability methods for spiking neural networks](https://doi.org/10.3389/fnins.2023.1153999), Frontiers in Neuroscience 17. Full publisher text checked. | Surrogate input attribution, spike deletion tests, and internal deletion noise already exist. Neither gradient spike attribution nor deletion testing is a new contribution here. |
| Elisa Nguyen, Meike Nauta, Gwenn Englebienne, Christin Seifert, [Feature Attribution Explanations for Spiking Neural Networks](https://arxiv.org/html/2311.02110), arXiv 2311.02110, full HTML checked. | Temporal Spike Attribution uses spike trains and weights, includes absent spikes, and tests input-feature inversion. Our test selects internal events under two specified local deletion meanings. |
| Julia Gygax and Friedemann Zenke, [Elucidating the theoretical underpinnings of surrogate gradient learning in spiking neural networks](https://arxiv.org/html/2404.14964v3), v3, 17 November 2024; journal version Neural Computation (2025), [DOI 10.1162/neco_a_01752](https://doi.org/10.1162/neco_a_01752). Full preprint and reset section checked. | Gives a stochastic account of surrogate gradients, examines reset derivatives, and uses the scaled fast-sigmoid form. Our deterministic ranking test does not claim a new derivative rule or an exact gradient of a discrete model. |
| Friedemann Zenke and Tim P. Vogels (2021), [The Remarkable Robustness of Surrogate Gradient Learning for Instilling Complex Function in Spiking Neural Networks](https://doi.org/10.1162/neco_a_01367), Neural Computation 33(4), 899–925. Primary indexed publisher text checked; direct full-page retrieval failed. [Author errata](https://zenkelab.org/publications/errata_zenke_vogels_2021/) checked. | Compares surrogate and reset-gradient choices during training. The current study changes only the local explanation graph after weights are fixed. It does not test training robustness. |
| Jinseok Kim, Kyungsu Kim, Jae-Joon Kim (2020), [Unifying Activation- and Timing-based Learning Rules for Spiking Neural Networks](https://papers.nips.cc/paper_files/paper/2020/file/e2e5096d574976e8f115a8f1e0ffb52b-Paper.pdf), NeurIPS 2020. Primary PDF checked, including the backward-path diagrams. | Already contrasts reset-gradient paths and relates spikes to later state changes. The current application compares exact effects and one-event selections under two local deletion queries; it does not introduce the reset-path distinction. |
| Mingyuan Sun and colleagues (2024), [EventRPG: Event Data Augmentation with Relevance Propagation Guidance](https://arxiv.org/html/2403.09274v1), v1, 14 March 2024. Abstract and method sections checked. | Layer-time relevance and guided event deletion are prior work. Our finite 2×2 test is not a new temporal explanation or relevance method. |
| snnTorch, [Tutorial 5: Training Spiking Neural Networks](https://snntorch.readthedocs.io/en/latest/tutorials/tutorial_5.html), documentation version 1.0.0, retrieved 13 October 2026. | A primary implementation reference for threshold forward rules, surrogate backward rules, voltage reset, cross-entropy and Adam. Our runner defines its own exact equations and has two spiking hidden layers. It is not a reproduction of the tutorial's model or results. |

The narrow question is whether a gradient that matches a local deletion graph selects a more consequential single event than the other graph. Both gradients keep all future reset derivatives. A positive result would apply to the fixed seeds, inputs, candidates, score, and model. It would not establish semantic completeness. A negative result would also be retained. No outcome has been collected at the time of this source record.
