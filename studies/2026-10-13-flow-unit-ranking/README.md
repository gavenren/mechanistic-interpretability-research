# Flow unit ranking

Status: plan and dummy checks are ready for review. No scientific model has run.

The proposed experiment compares two ways to select a neuron for removal from a small flow model. One selector uses likelihood damage. The other uses changes in generated quadrant frequencies. The selected units will be compared on separate test samples. Quadrant frequencies are a coarse output measure.
