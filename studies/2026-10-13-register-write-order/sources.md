# Checked primary sources

Checked 13 October 2026. These sources bound the claim. The search is not a proof that no earlier work used this exact test.

1. Benjamin Shih, John Winnicki, and Eric Darve. *When Does Activation Steering Change What a Model Computes From?* [arXiv:2606.29522v2](https://arxiv.org/abs/2606.29522v2). Checked the versioned full text, state-edit methods, continuation controls, and multi-step tests. This work already separates immediate steering from state that the model uses later. It uses controlled group-state tasks and includes persistence tests. Our narrow addition is a paired copy/write order test with irreversible writes, and a fixed comparison of two training losses. We do not claim to introduce downstream state-use tests.

2. Yang Liu and Yuming Chen. *Low-Rank Dynamics-Effective Latent Carriers for Counterfactual Rollout in Learned World Models.* [arXiv:2608.15156v4](https://arxiv.org/abs/2608.15156v4), revised 7 September 2026. Checked the abstract, methods, and control tables in the versioned PDF. This is especially close: it tests one-time low-rank edits, later autonomous computation, specificity, native counterfactual capability, and a full-hidden-state interface control. Our task has two discrete registers and paired propagation/erasure requirements. That is a different local experiment, not a new account of causal state.

3. Róbert Csordás, Christopher Potts, Christopher D. Manning, and Atticus Geiger. *Recurrent Neural Networks Learn to Store and Generate Sequences using Non-Linear Representations.* [BlackboxNLP 2024, pp. 248–262](https://aclanthology.org/2024.blackboxnlp-1.17/). Checked the ACL record and methods in the published PDF. It uses learned interventions to examine recurrent sequence representations and shows limits of linear alignment. A failed rank-four edit in our model would not prove that the register is absent or unusable. A nonlinear edit could behave differently.

4. Atticus Geiger, Zhengxuan Wu, Christopher Potts, Thomas Icard, and Noah Goodman. *Finding Alignments Between Interpretable Causal Variables and Distributed Neural Representations.* [CLeaR 2024, PMLR 236:160–187](https://proceedings.mlr.press/v236/geiger24a.html). Checked the primary record and method description. Distributed Alignment Search learns alignments through interchange interventions. Our orthogonal subspace replacement uses this established intervention idea. The contribution is a fixed stress test and loss comparison, not a new alignment method.

5. Yuntai Bao and colleagues. *Faithful Bi-Directional Model Steering via Distribution Matching and Distributed Interchange Interventions.* [arXiv:2602.05234v2](https://arxiv.org/abs/2602.05234v2). Checked the versioned primary abstract. It changes alignment objectives to improve faithful counterfactual steering. Thus, changing an intervention training loss is also not new in itself. Our immediate-versus-one-step comparison asks a narrower question under a fully specified state machine.

The source checks found strong conceptual overlap. We will describe any result as a small controlled extension and report failures. The model is trained for this study. It is not a pretrained language model.
