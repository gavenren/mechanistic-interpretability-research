The fixed-case resampling interval included zero. Plan lock: `4dc5db20c261f9057d08a4ad2c7cc9548dcba1ba`. The complete study was verified on GitHub at `0d8888bb432e2ca3682da7d214e263e76e06b114`.

5. [How one attention head selects and copies a supplied value](../studies/2026-10-13-copy-routing/paper.md). The selected head was layer 3, head 1. Route and value changes reduced the test binding score by 5.882 and 5.743 logit units. Their combination recovered 5.780 units relative to the route change. Full-vocabulary top-token accuracy was 29.2%; the higher two-answer preference rate is a different measure. All planned controls and independent checks passed. The separate model replay covered every baseline and all 1,152 selected-head intervention examples. Plan lock: `512fdba309df32aa3a98db59c65ec5d5d383635f`. The complete study was verified on GitHub at `278d675fae5311da7215b8c984ca48854b6c7541`.
6. [Selecting a patch site for a later output effect](../studies/2026-10-13-patch-memory/paper.md). The immediate selector chose block 4; the eight-token selector chose block 3. Their held-out later TV scores were 0.000272 and 0.002866. This is generic output sensitivity, not task success: no prompt had its requested copy word ranked first. All planned controls and a separate full-prefix replay of all 3,456 patch measurements passed. Plan lock: `512fdba309df32aa3a98db59c65ec5d5d383635f`. The complete study was verified on GitHub at `278d675fae5311da7215b8c984ca48854b6c7541`.

7. [A joint test of position spacing and access to extra tokens](../studies/2026-10-13-position-access/paper.md). At gap 128, blocking fillers alone and compressing position coordinates alone each sharply reduced the score. Their fixed contrast was +0.209 logits, with interval [0.021, 0.395]. Both edits together matched the short-input control. Native long inputs had lower mean margins but higher full-vocabulary top-1 accuracy. All fixed controls and the separate full replay of 6,144 scored outputs passed.
8. [Same text, different token splits](../studies/2026-10-13-segmentation-transfer/paper.md). Matching splits had 99.12% two-answer accuracy and 44.43% full-vocabulary top-1 accuracy. An added float64 probability check failed; its original code, receipt, and numerical diagnostic remain. The maximum probability difference was 0.0000772. Logit and ranking conclusions were unchanged.

A separate audit replayed all 144 evaluated checkpoints and 198,144 intervention rows. It checked training records but did not repeat the training trajectories.
